# submissions

Your work goes in your own folder:

```
submissions/
  <your-github-handle>/
    00-onboarding/profile.json
    01-oop-refresher/nn.py
```

The handle has to match your GitHub username — the check compares it against the pull request
author.

Read other people's folders once their work is merged; seeing four ways through the same module is
worth more than extra practice. Don't edit anyone else's. If you have a suggestion, leave it as a
review comment on their pull request.

New here: [`modules/00-onboarding/TASK.md`](../modules/00-onboarding/TASK.md).
