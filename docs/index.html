Reps until AI research and engineering feel ordinary.

Every module is a small piece of a neural network you build yourself, submitted as a pull request, checked by a robot and reviewed by a human. You never have to run a test on your own machine — opening the pull request is running the tests.

Start here

Fifteen minutes, and you will have done the whole loop once.

  1. Claim your corner

    Make a branch called your-handle/00-onboarding and add submissions/your-handle/00-onboarding/profile.json. Copy the starter and fill it in.

  2. Open a pull request

    A check runs by itself and leaves a comment listing, in plain English, what passed and what did not. Push again and the same comment updates. Nothing to install.

  3. Get it reviewed, then merge

    One teammate reads it and approves. Your row appears below. Then take module 01, and from there the neural network starts.

The track

Fundamentals first, in NumPy, so nothing is magic. Then the same things in PyTorch. Then an LLM, following Sebastian Raschka's Build a Large Language Model (From Scratch) chapter by chapter. Then the part that makes it research rather than tutorials.

Built by the people in it. Add a reading, fix a check, improve a task — all of it is a pull request.
