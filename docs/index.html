research-gym

Build a neural network from scratch, then an LLM. One module at a time, submitted as a pull request that gets checked automatically and reviewed by someone on the team.

You don't run tests yourself. Opening the pull request runs them, and a comment tells you what passed.

Starting

  1. Make a branch your-handle/00-onboarding.
  2. Add submissions/your-handle/00-onboarding/profile.json.
  3. Open a pull request. Wait for the check, get a review, merge.
  4. Take module 01.

Everything works from the browser — press . on the repo to get an editor. See the repo's CONTRIBUTING.md.
